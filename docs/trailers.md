# Hero 预告片（YouTube only）

`GET /tmdb/{movie|tv}/trailers?id=693134&language=zh-CN&v=2`

返回稳定的视频 ID 和候选所对应的 App 语言，例如：

```json
{"youtube":["_YUzQa_1RCE"],"language":"zh"}
```

筛选仅接受 YouTube 的 Trailer / Teaser，排除花絮、片段和无效 ID。先选择 App 语言（按 ISO 639-1 匹配，例如 zh-CN/zh-TW 都匹配 zh）；该语言没有候选才用影片的 `original_language`。同语言内按官方、正式 Trailer、1080p 标签排序，去重最多三个。两种语言都没有时返回空列表，不补英语。官方与语言以 TMDB 标记为依据，标签不保证源实际提供 1080p。

轮播列表、新爬虫快照和新发布区块在现有详情/图片请求中附带 videos，并内嵌 `trailer` 字段。已知原始语言时与 App 语言合并查询，不新增 TMDB 请求；未知原始语言且首选语言没有候选时，补一次原始语言视频查询。客户端检查内嵌候选的 language，旧快照或不同 App 语言的数据改走候选接口，不批量重发旧区块。候选缓存 24 小时、空结果 10 分钟；上游失败不缓存为空结果，并发请求合并。缓存版本已更新。

`GET /tmdb/trailers/rules` 下发匿名客户端参数、visitor 提取规则和 JSON 字段路径，缓存 5 分钟。失败时客户端使用内置规则。后端不访问 YouTube，也不转发或存储视频。

三端共享 Swift 解析器，设备直连 YouTube，按排序依次尝试当前项的候选，成功即停止（最多 3 条，不并行预解析全部轮播项）：每条包含网页、player、HLS master 三次解析请求。成功结果取 player 的 expiresInSeconds 与清单、音视频、字幕 URL 签名过期时间中的最早值，提前 60 秒停止复用；无法确定有效期时不缓存成功结果。失败缓存 1 分钟，手动重试可清除失败缓存。挑选最高不超过 1080p 的 AVC 视频，并保留对应音轨。过滤后的 master 仅在本机回环地址提供，音视频清单与分片直连 YouTube CDN。

字幕复用同一次 YouTube player 响应里的 `captionTracks`，不新增元数据请求；有可用轨道时由设备额外取一次 timedtext JSON3。按用户的首选字幕语言选择，自动设置跟随 App 语言，同语言优先人工字幕。字幕以 AVPlayer 时钟显示，保留原时间轴；没有源字幕、字幕请求失败或无法匹配/翻译时不显示，不做语音识别。

iOS 26 / macOS 26 及以上，在没有首选语言字幕时使用 Apple Translation 翻译已有字幕，前提是语言对受支持且设备已安装语言包；首页自动播放不弹下载窗口。旧系统和 tvOS 只显示匹配语言的源字幕。字幕请求和翻译不阻塞视频起播，成功字幕按视频/语言缓存 30 分钟，切换影片或关闭预告片后取消显示。

不再解析 IMDb，也不查找 IMDb 预告片。没有候选或播放失败时显示原图，首页恢复正常轮播。保留完整播放、图片淡入淡出、垂直滚动继续播放、设备独立开关和各端原有静音按钮规则。

YouTube 使用非官方协议；地区、网络或协议变化仍可能导致解析/播放失败。规则可服务端更新，协议结构大改仍可能需要更新 App。
